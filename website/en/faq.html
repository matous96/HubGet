Questions and answers

Frequently asked questions

Edge says the installer “isn’t commonly downloaded”. What should I do?

Edge judges downloads by their reputation. A new installer that isn’t digitally signed yet and has been downloaded by only a few people doesn’t have any, so Edge warns – it doesn’t mean the file contains a virus. Only download HubGet from this website or from the official releases on GitHub. In Edge, hover over the download and click … → Keep → Show more → Keep anyway. Windows SmartScreen may warn once more when you run it – see the next question. We’re preparing a free code signing certificate for open source (SignPath Foundation); with it, the warning should disappear over time.

Windows shows a SmartScreen warning when I run the installer. Is that okay?

The HubGet installer isn’t digitally signed yet, so Windows shows the “Windows protected your PC” dialog. Click More info and then Run anyway. A signed installer is on our roadmap.

What does “preview” mean?

HubGet is still in an early stage of development – the first public version 0.1.0 came out in October 2026 and updates have been arriving since (see What’s new). WinGet, Chocolatey, Scoop and developer package managers (npm, pip, Cargo and more) work for real – search, install, update and uninstall. You may run into the occasional bug.

Is HubGet free?

Yes. HubGet is open source under the MIT license – free, with no ads and no bundled extras. The source code is on GitHub.

Do I need an account?

No. Signing in with GitHub is optional and only needed for ratings, reviews, adding screenshots and sync between computers. Installing, updating and uninstalling work without an account. The privacy policy describes what's stored when you sign in.

Where does HubGet download apps from? Is it safe?

Only from the official repositories of package managers. HubGet downloads the installer and WinGet verifies its SHA-256 checksum before running it – if the file differs from the published one, the installation doesn’t happen.

Will HubGet show apps I installed before?

Yes. The installed apps overview includes programs installed outside WinGet, Microsoft Store apps and Steam games. You can update them, uninstall them or launch them with the Open button.

Do I need administrator rights?

Not to install HubGet – the EXE installer installs for the current user. If installing an app requires administrator rights, HubGet retries it and asks for them (UAC).

What’s the difference between the EXE and MSI installers?

The EXE is recommended for most people: it installs without administrator rights and offers English and Czech. The MSI is meant for deploying across a company.
